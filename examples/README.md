# Debug Examples

This directory contains example components that demonstrate various debug patterns. These are for reference only and should not be imported into the main application.

## Directory Structure

- `/debug/` - Debug-related example components
  - `AsyncExample.js` - Shows how to debug async operations
  - `FormExample.js` - Shows how to debug form state

## Usage

These examples are for reference only. They should not be imported into the main application as they may interfere with the actual debug functionality.

To view these examples:
1. Create a new test component
2. Copy the relevant example code
3. Test in isolation from the main application

## Best Practices

When implementing debug functionality in the main application:
1. Only track explicitly requested debug variables
2. Keep debug information focused and relevant
3. Avoid tracking internal state unless specifically needed
4. Document all debug variables being tracked
