# Make Rotas Documentation

> ⚠️ This project includes both application features and development-only meta features. Please refer to meta_features.md for development tools that should not be included in production.

## Documentation Files
1. `feature.md` - Feature implementations and technical details
2. `development.md` - Development guidelines and best practices
3. `quality_control.md` - Quality control documentation
4. `accidental_duplication.md` - Record of duplications and resolutions
5. `variables_and_functions.md` - Technical reference for codebase structure
6. `meta_features.md` - Development-only tools and features

## File Purposes
- `feature.md` - Documents all implemented features with their technical details
- `development.md` - Contains coding standards and development workflows
- `quality_control.md` - Tracks quality measures and improvements
- `accidental_duplication.md` - Maintains a log of duplication incidents and their resolutions
- `variables_and_functions.md` - Provides a detailed reference of variables, functions, and component structures
- `meta_features.md` - Documents development tools and features that should be removed in production

## Documentation Categories
1. **Application Features** - Actual product features that will be deployed
2. **Development Tools** - Meta features for development and debugging only
3. **Quality Control** - Documentation for maintaining code quality
4. **Technical Reference** - Code structure and organization details
